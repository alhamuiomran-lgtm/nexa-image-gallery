# RC1 static visual preview

Serve this directory as the web root (for local review: python3 -m http.server 8080 --bind 127.0.0.1), then open http://127.0.0.1:8080/. Opening HTML directly from disk is unsupported because asset paths are root-relative. On static hosting, publish only this directory and preserve its route folders and 404.html.

155 actual anonymous RC1 pages are visual snapshots, with local licensed assets. Requests/search/forms/backend/login are unavailable and form controls deliberately disabled. No test database or credentials are supplied. Admin/editor gallery panels are actual screenshots, not accessible admin sessions. Install the separate qualified product ZIP in an isolated WordPress site to test live editing/import/forms. SMTP requires a separately authorized mail transport.

Public deployment and its final-origin checks remain pending confirmed owner hosting. This archive is not a production WordPress site or marketplace approval. Read credits.html and docs before publication.
