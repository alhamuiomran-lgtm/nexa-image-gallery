Edit your site

Edit pages and sections

Open a page in the WordPress block editor. Select headings, paragraphs, buttons or images to edit their content. Use the Media Library to replace images and provide useful alternative text. Keep appropriate image dimensions to avoid layout shifts.

Insert patterns

Use the Pattern Library for reusable section designs and its design/category filters and page navigation. Studio selects whole designs; the Pattern Library selects components. Insert a component into the current document, edit it, save, then reopen the page and check its preview.

Global identity

Use Brand Settings for the identity controls offered by the product, and WordPress menus for navigation. Check both desktop and mobile navigation after changing links.

Safe customization

Install the supplied nexa-service-child.zip after its parent, then activate NEXA Service Child. The parent remains installed; child style.css loads after parent presentation CSS. Put your CSS in child style.css and hooks in child functions.php. Do not copy the parent functions.php. Copy only templates you need, preserving their relative paths. Review overrides after parent updates. Updating the parent preserves child files; uploading the starter child again overwrites your child customizations. Use a child theme for PHP template overrides. Keep custom code outside the parent theme and Companion directories so updates can replace their files. Back up customizations before updating.

Companion and saved content

Companion supplies dynamic NEXA blocks and content types. Deactivating it can remove their editor controls and frontend rendering. Reactivate the matching plugin to restore those features. Back up before removing plugins; deactivation is not a content migration to another theme.
