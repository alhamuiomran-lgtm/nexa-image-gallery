Studio and demo import

Choose a design

Open NEXA → Studio. Climate, CODALINE, ORBITA, VIVID, LUMEN, STRATUM and SOLSTICE are available. Studio shows four cards on its first page and three on its second page. Use Preview or Explore Sections before importing.

Import with explicit choices

  1. Open the selected design’s Import Demo control.
  2. Read the confirmation and select the import operation.
  3. Choose whether to change the front page, navigation assignment, visual settings or site title where those options are offered.
  4. Confirm the import and wait for its result. Keep the tab open.

Leave shared-setting changes unselected when you want to keep your current settings. Demo imports create example content; they do not establish that illustrative companies, teams, results or projects are real.

Retry and re-import

If a connection is interrupted, retain the result/error message, reload Studio and retry the same design. Re-import is designed to reuse owned demo records and preserve edited content. Keep a backup and review the result on staging; do not use import as a reset or restore tool.

Verify the result

Check every imported page, service, project and article, menus, images, header/footer, buttons and forms. Replace illustrative claims and contact details. Confirm changes on desktop and mobile. Importing another design is not a cleanup operation for the first design.

Image availability

Only images marked as eligible in the final package’s image manifest may be distributed. Preview-only images may differ from the customer download. Do not obtain a preview image through an undocumented remote URL or assume that free stock photography includes every release you need.

Consult the release test matrix and license manifest before using a release candidate commercially.
