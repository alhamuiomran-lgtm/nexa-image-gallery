Image licensing and replacement

Read the manifest

For each packaged image, consult the original source, creator, license, evidence, file hash and allowed use. A preview-only label excludes that image from buyer ZIPs and demo-import downloads unless a separately documented permission covers the intended delivery.

Commercial rights

A photograph’s copyright license does not automatically provide permission for identifiable people, private property, artwork, products or trademarks depicted in it. Review your intended use and avoid misleading endorsements or claims of actual staff or completed projects.

Your own photographs

Upload images you own or may use under a suitable license. Replace the image block through the Media Library, preserve a sensible crop, set alternative text, save and reopen the page. Check responsive views and avoid very large source files when a smaller image is sufficient.

External services and excluded imagery

No developer API key belongs in a buyer download or frontend page. An external image URL is not proof of redistribution rights. Only the assets identified in the supplied license manifest are candidates for inclusion; source and license notices remain attached. Historical excluded assets are not permission to obtain or redistribute them.

Consult the release test matrix and license manifest before using a release candidate commercially.
