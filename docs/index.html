NEXA Service guide

NEXA Service provides seven business and service website designs built with the WordPress block editor. NEXA Companion adds services, projects, Requests, Studio, custom blocks and demo import.

Start here

  1. Back up your site and prepare a staging copy.
  2. Install the theme and, when you need its additional features, the matching Companion plugin.
  3. Open NEXA Studio, review a design and choose the import options.
  4. Replace example content and imagery with material you may use commercially.
  5. Test navigation, mobile layouts and message delivery before publishing.

Release candidate status

This is the offline guide for NEXA Service 1.0.0 and NEXA Companion 1.0.0 candidate. Read RELEASE-STATUS.json and COMPATIBILITY.md in the complete download for exact package qualification and remaining gates. A version number does not imply marketplace approval or readiness for sale.

Supported versions

Both products require WordPress 6.6 or later and PHP 8.1 or later. Recorded source qualification includes WordPress 6.6 and 7.1.3 with PHP 8.3.35 and eight actual HTTP/editor/Studio runtime pairs on PHP 8.1.34, 8.2.34, 8.4.27 and 8.5.12. MariaDB 11.4 was used. WordPress 6.6 with PHP 8.5 has an upstream Core deprecation; prefer current WordPress. These exact tests do not certify every hosting version or every flow. See COMPATIBILITY.md for the retained source bindings and limits.
