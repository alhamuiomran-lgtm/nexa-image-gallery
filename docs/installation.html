Install NEXA

Prepare a safe installation

Create a complete database and files backup. Confirm you can restore it. Use staging first, and keep the previous working theme and plugin archives.

Install the theme

  1. Extract the outer download on your computer.
  2. In WordPress, open Appearance → Themes → Add New → Upload Theme.
  3. Upload the installable nexa-service.zip, then activate NEXA Service.

Do not upload the outer documentation/commercial bundle as a theme. A “missing style.css” error commonly means that the wrong ZIP was selected.

Choose whether to install Companion

Standard posts, pages, archives, search and comments work without Companion. Additional NEXA content types, custom blocks, Requests, Studio and import require it.

When the theme download includes the matching installer archive, the optional setup screen explains the plugin. Choose Install, then Activate separately. Alternatively, use Plugins → Add New → Upload Plugin and select nexa-companion.zip. A development build without the bundled archive displays an information notice; obtain the complete matching download instead of using an unknown plugin source.

Before importing

Check the installed versions, write permissions and available disk space. The parent theme ZIP is about 30 MB and Companion about 20 MB; hosting upload and POST limits must exceed the exact archive size. Ask your host to raise them if the upload is rejected. Review existing content and site settings. Install on a clean staging site when evaluating a new design.

Consult the release test matrix and license manifest before using a release candidate commercially.
