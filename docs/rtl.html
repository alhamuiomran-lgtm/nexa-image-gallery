Arabic and right-to-left content

Choose the site language

Set Arabic or another right-to-left language in Settings → General. Use WordPress language packs and translated strings where available.

Review translated content

Check long headings, mixed Arabic/English text, numbers, phone numbers, buttons, forms, menus, editor previews and Studio. Verify keyboard focus and dropdown controls on mobile. Theme/plugin text-domain translation and RTL behavior require their own validation; translating page text alone does not establish complete RTL compatibility.

Compatibility scope

Recorded Arabic/RTL tests cover frontend navigation, forms, Gutenberg and Studio on three actual browser engines. Arabic catalogs are practical and partial; marketing copy remains English and editable. Theme translations use nexa-service, plugin translations nexa-companion. Copy the relevant POT from languages/, create your locale PO and MO with a gettext tool, and keep custom translations in WordPress language directories outside replaceable product folders (for example wp-content/languages/themes/nexa-service-ar.mo). The bundled theme-local Arabic catalog is languages/ar.mo. Translate page content and menus separately. Recheck layout and meaning after translating. No WPML or Polylang certification is claimed. Evaluate any multilingual plugin independently on staging.

Consult the release test matrix and license manifest before using a release candidate commercially.
