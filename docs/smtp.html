Configure and test email

Connect an authorized mail service

Use a maintained SMTP or transactional-mail plugin and an account you control. Follow the provider’s instructions for hostname, port, TLS and authentication. Store credentials through the plugin’s supported configuration; never place them in the theme, public JavaScript, screenshots or a Git repository.

Verify external delivery

  1. Configure the sender domain and any required SPF, DKIM and DMARC records with your mail provider.
  2. Send the mail plugin’s test message to an inbox you control.
  3. Submit an actual website request and confirm receipt in that inbox.
  4. Check spam filtering and provider logs if it does not arrive.

Saving a request locally or a successful local mail capture does not prove external delivery. Real SMTP delivery for the release candidate is not verified without authorized transport credentials and a controlled recipient.

Privacy

Do not send customer data to an unrelated address during testing. Restrict access to Requests, set an appropriate retention process and describe your mail provider and processing in your privacy notice.

Consult the release test matrix and license manifest before using a release candidate commercially.
